# Imagens do LusoFolio

- `lusofolio-icon.png`: recurso original da aplicação instalada, também preservado no portfólio do proprietário. Sem redesenho.
- `lusofolio-hero.png`: composição editorial em HTML/CSS, com o ícone original e a captura do inventário. O enquadramento da capa é decorativo.
- `dashboard.jpg`, `inventory.jpg`, `portfolio.jpg`, `item-details.jpg` e `trading-desk.jpg`: capturas dos recursos da interface da instalação Windows identificada como LusoFolio 0.2.1, renderizados localmente através do suporte de armazenamento no navegador já existente nessa interface.

Os registos, valores, datas e configurações usados na apresentação são fictícios. As capturas não reproduzem a conta do proprietário. Não houve sincronização ativa: os pedidos externos foram bloqueados no ambiente de captura e as imagens públicas dos itens foram carregadas a partir de cópias locais. A base de dados e as credenciais reais não foram incluídas neste repositório.

Foi verificada a navegação entre dashboard, inventário, detalhe de item, portefólio e Trading Desk, sem erros de JavaScript ou imagens em falta no ambiente de demonstração. Isto não certifica a sincronização, as permissões de uma conta CSFloat ou todos os fluxos da aplicação Windows. A versão de produto anunciada para descarga é a do instalador publicado; as imagens identificam a instalação observada, sem afirmar equivalência binária entre builds apenas por partilharem o número de versão.

Imagens, nomes e marcas CS2/Valve e CSFloat mantêm os direitos dos respetivos titulares. Os preços fictícios não são cotações nem uma demonstração de rendimento real.
